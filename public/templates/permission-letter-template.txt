PERMISSION LETTER TEMPLATE VARIABLES:

The following variables should be used in the Word document template:

{{date_today}} - Current date
{{visitor_name}} - Name of the visitor
{{visitor_affiliation}} - School/organization affiliation
{{email}} - Email address
{{phone}} - Phone number
{{organization_type}} - Type of organization (School, Company, etc.)
{{school_name}} - School name (if applicable)
{{course}} - Course name (if applicable)
{{organization_name}} - Organization name
{{purpose}} - Purpose of visit
{{date_requested}} - Requested date
{{time_requested}} - Requested time
{{guests}} - Number of guests
{{package_name}} - Package name

CORRECT FORMAT:
All variables should be enclosed in double curly braces: {{variable_name}}

INCORRECT FORMATS TO AVOID:
- {{date (missing closing brace)
- {{visi (incomplete variable name)
- oday}} (missing opening brace)
- tion}} (missing opening brace)
